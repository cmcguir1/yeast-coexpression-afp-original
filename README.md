This repository contains the original implementation of the methodolgy found in McGuire and Hibbs 2025. An updated implementation can be found at [yeast-coexpression-afp](https://github.com:cmcguir1/yeast-coexpression-afp). The original implementation of these algorithms are computationally inefficient. The new repository was created to provide computationally efficient implementations of our methodologies and an easy to set up virtual environment to improve the reproducability of our results.
